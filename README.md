## Markdown 格式规范

所有文章均使用标准 Markdown 格式编写：

- **代码块**：使用三反引号格式 ` ```language ` 并指定语言标识符
  - Ruby 代码：` ```ruby `
  - JavaScript 代码：` ```javascript `
  - Bash 命令：` ```bash `
  - YAML 配置：` ```yaml `
  - 等等...

- **列表**：使用 `-` 作为无序列表标记

- **标题**：文章标题使用一级标题 `#`，章节使用二级及以下标题
